## 它解决什么问题

小明的妈妈最近很郁闷。小明上小学一年级后，老师要求**每天完成 30 道口算题**，
于是"出题、抄题、批改、讲错题"成了她每天下班后的固定负担：

- 手写 30 道题要 10 分钟，孩子做完后批改又要 5 分钟，一天 15 分钟；
- 出题难度全凭感觉，一会儿太简单孩子没兴趣，一会儿太难孩子直接哭；
- 错题抄在本子上，隔几天想重练一遍，翻半天找不到同类题；
- 想看看孩子到底哪个知识点弱，只能靠"感觉"。

本期采用在线练习路径，减少家长出题、批改和整理错题的重复劳动。原访谈材料中的纸质作业场景属于需求来源；根据用户 2026-10-25 的明确决定，本期不提供纸面输出。

产品目标是贯通出题、在线作答、自动批改、成绩历史、错题重练与学情统计。实际完成范围见上方“当前可用版本”。

## 产品功能规划（以“当前可用版本”为准）

| 功能 | 说明 |
|---|---|
| 🎲 **智能出题** | 按年级 / 知识点 / 题型自动组卷，题量、难度可调，每次题目都不重样 |
| ✍️ **在线答题** | 数字键盘 / 实体键盘输入，逐题即时判对错，支持倒计时与用时统计 |
| ✅ **自动批改** | 提交即出分，正确率、用时、错题清单一屏呈现 |
| 📕 **错题本** | 错题自动归档，支持"错题重练"与"举一反三"（同知识点生成变式题） |
| 📊 **学情报告** | 正确率趋势、知识点掌握度、每日练习量统计，看清孩子的薄弱环节 |
| 👦 **多孩档案** | 一台设备管多个孩子，各自独立记录互不干扰 |
| 📱 **PWA 可安装** | 手机浏览器"添加到主屏幕"，像 App 一样离线可用 |

## 知识点覆盖（人教版教材口径）

**一年级**：10 以内加减法 · 20 以内进位加 / 退位减 · 100 以内整十数加减 · 100 以内数的认识

**二年级**：100 以内两位数加减（进位 / 退位）· 表内乘法（九九表）· 表内除法 · 万以内数的认识与整百整千加减

**三年级**：多位数乘一位数 · 两位数乘两位数 · 除数是一位数的除法 · 两步混合运算（含括号）· 同分母分数加减 · 一位小数加减

> 覆盖三个年级、共 **24 个知识点**，正好满足"买一个软件用三年"的诉求。

## 快速开始

本项目是**零第三方运行时依赖的纯静态网页**，无需构建。本地运行需使用 HTTP 静态服务，浏览器通过 ES Module 加载代码。

```bash
# 在项目根目录启动本地静态服务
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```

在线试用：[GitHub Pages](https://holer0917.github.io/child-learning/)。

## 技术选型

| 层 | 选型 | 理由 |
|---|---|---|
| 结构 | 原生 HTML5 | 零依赖，任何浏览器可跑，部署成本为零 |
| 样式 | 原生 CSS + CSS 自定义属性 | 统一白色极简界面，适配手机与电脑 |
| 逻辑 | 原生 ES Module | 免构建，模块边界清晰，可直接用浏览器调试 |
| 存储 | localStorage | 免注册、免后端，学生数据不出本机（隐私友好） |
| 图表 | 手写 SVG | 无第三方库，体积可控，完全契合无障碍配色规范 |
| 发布 | GitHub Pages；代码同时维护于 GitHub / Gitee | 已有在线试用入口；后续发布按用户指令执行 |
