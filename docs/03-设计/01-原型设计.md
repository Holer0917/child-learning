## 二、核心用户流程

### 2.1 主流程：出卷 → 打印（家长最高频路径）

> **设计目标：3 次点击完成。** 这是本项目的价值主线，必须最短。

```
        ┌─────────────┐
        │  P1 出题台   │
        │  ①选年级     │
        │  ②选题量     │
        │  [开始出题]  │◄──── 点击 1
        └──────┬──────┘
               │
               ▼
        ┌─────────────┐
        │  P3 组卷预览 │
        │  展示 30 道题 │
        │  [打印]      │◄──── 点击 2
        └──────┬──────┘
               │
               ▼
        ┌─────────────┐
        │  P12 打印预览│
        │  浏览器打印   │
        │  [打印/保存] │◄──── 点击 3
        └─────────────┘
```

**耗时目标**：30 秒内完成。

### 2.2 副流程：出题 → 在线答题 → 批改

```
P1 出题台 ──► P3 组卷预览 ──► P4 在线答题 ──► P5 成绩结算
                                    │              │
                                    │              ├──► P6 错题本
                                    │              │
                                    ▼              └──► P7 举一反三
                              （即时判分）
```

### 2.3 副流程：错题攻坚

```
P6 错题本 ──► 选中知识点 ──► [重练] ──► P4 在线答题 ──► 答对 → 标记"已攻克"
      │
      └──► [举一反三] ──► P7 ──► 生成 3 道变式题 ──► P4 答题
```

**设计要点**
- 出题四步在同一屏完成，**不跳页**，避免家长在多页之间来回；
- 主按钮显示"（30 道）"，实时反映当前设置，避免误操作；
- 年级默认取当前档案的年级，减少一次操作；
- 知识点默认勾选该年级全部，家长若不调整可**直接点出题**。

## 四、交互细节规范

### 4.1 触控与输入

| 场景 | 规范 |
|---|---|
| 最小触控区域 | 44 × 44 px（满足 NFR-02） |
| 数字键盘按键 | 64 × 64 px，间距 8px |
| 答题输入 | 支持触屏数字键盘 + 物理键盘数字键 + 回车提交 + 退格删除 |
| 负数/小数输入 | 提供 `-` 与 `.` 按键（仅当题目涉及负数或小数时显示） |
| 竖式题输入 | 每个数位一个独立输入格，自动跳转下一格 |

### 4.2 反馈时机

| 事件 | 反馈 | 时长 |
|---|---|---|
| 点击主按钮 | 按钮按下态 + 加载态 | 即时 |
| 出题完成 | 直接跳转预览页 | < 50ms |
| 答题正确 | 绿色对勾 + 轻微缩放动效，自动进入下一题 | 400ms |
| 答题错误 | 红色叉号 + 抖动 + 显示正确答案 | 停留至用户操作 |
| 全部答对 | 全屏庆祝动效 | 1.5s，可点击跳过 |
| 数据保存 | 右上角轻提示"已保存" | 1.5s 后自动消失 |

### 4.3 错误处理

| 错误场景 | 处理方式 |
|---|---|
| localStorage 不可用（隐私模式） | 顶部横幅提示"当前浏览器不支持本地存储，数据将无法保存"，功能仍可用 |
| localStorage 数据损坏 | 捕获异常 → 备份损坏数据到 `__corrupt__` 键 → 以全新状态启动 → 提示用户 |
| 存储空间不足 | 提示"存储空间不足，请导出数据后清理旧记录" |
| 导入文件格式非法 | 提示"文件格式不正确，请选择由本软件导出的备份文件" |
| 题目生成失败（参数矛盾） | 自动放宽约束重试；仍失败则提示"当前条件无法出题，请调整知识点或题量" |

| 项目 | 内容 |
