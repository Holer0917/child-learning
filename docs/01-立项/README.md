## 立项结论（摘要）

| 项目 | 内容 |
|---|---|
| **项目名称** | 口算小达人（KidsMath） |
| **选题来源** | 课程选题参考第 2 题「儿童学习」 |
| **一句话定位** | 面向小学 1–3 年级家长的**口算练习一站式工具**：出题、批改、错题重练、A4 打印 |
| **目标用户** | ① 主要用户：陪写作业的小学生家长；② 直接用户：1–3 年级小学生 |
| **核心价值主张** | 把家长每天 15 分钟的"出题 + 批改 + 抄错题"压缩到 30 秒 |
| **交付形态** | 纯前端 Web 应用（PWA 可安装），部署于 Gitee Pages，普通用户联网即可试用 |
| **团队规模** | 3 人 |
