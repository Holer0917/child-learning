## 三、发现的问题清单

### P-01【遗漏】缺少"教材对标校验"需求

| 项目 | 内容 |
|---|---|
| **提出人** | 老师 D（领域专家） |
| **原文** | "一年级上学期还没学进位加法，家长就开始出 8+7 了。**超纲是最常见的**。你们必须保证出的题和教材进度一致。" |
| **影响** | 高。超纲题会让孩子挫败，家长会归咎于软件 |
| **处理** | ✅ **采纳**。新增 **FR-06 教材对标校验**，并要求知识点大纲中每个知识点显式定义数值范围约束 |
| **状态** | 已修复 |

### P-02【遗漏】缺少"答案页打印"需求

| 项目 | 内容 |
|---|---|
| **提出人** | 家长 A（用户代表） |
| **原文** | "打印出来孩子做完了，**我还是得自己一道道算一遍看对不对**啊。" |
| **影响** | 高。只打印卷不打印答案，家长仍然要花 5 分钟批改，核心价值被削弱 |
| **处理** | ✅ **采纳**。新增 **FR-26 答案页打印**，并明确答案页与练习卷的题目顺序必须一一对应 |
| **状态** | 已修复 |

### P-03【遗漏】缺少"数据备份"需求

| 项目 | 内容 |
|---|---|
| **提出人** | 周明灏（测试负责人） |
| **原文** | "数据只存在 localStorage 里，用户一清缓存、一换手机就全没了。家长 C 有两个孩子，攒了半年的记录丢了会骂人的。" |
| **影响** | 中。数据丢失是用户流失的致命因素 |
| **处理** | ✅ **采纳**。新增 **FR-28 数据导出与导入**（优先级 Should） |
| **状态** | 已修复 |

### P-04【不可测试】FR-09 难度分级缺少量化标准

| 项目 | 内容 |
|---|---|
| **提出人** | 周明灏 |
| **问题** | 原文"优先生成低星级题目"——"优先"是模糊的，无法判定是否达标 |
| **处理** | ✅ **采纳**。补充量化标准：选择"简单"档时，卷子中 1 星题占比 ≥ 70%；"挑战"档时 3 星题占比 ≥ 50% |
| **状态** | 已修复 |

### P-05【不可测试】FR-15 激励反馈"简短"无定义

| 项目 | 内容 |
|---|---|
| **提出人** | 周明灏 |
| **问题** | 原文"播放简短的视觉动效"——"简短"如何判定？ |
| **处理** | ✅ **采纳**。补充：动效时长 200 ~ 400ms，不阻塞答题流程 |
| **状态** | 已修复 |

### P-06【不可测试】NFR-02 易用性第 1 条无法客观测量

| 项目 | 内容 |
|---|---|
| **提出人** | 屠生豪 |
| **问题** | 原文"使新用户在无需阅读说明书的情况下于 1 分钟内完成首次出卷"——"无需阅读说明书"不可客观判定 |
| **处理** | ✅ **采纳**。改为可操作定义：邀请 5 位未接触过本软件的家长，仅提供软件入口 URL，观察其能否在 1 分钟内完成首次出卷；成功人数 ≥ 4 人（80%）为达标 |
| **状态** | 已修复 |

### P-07【不可测试】FR-16 评价等级边界不明确

| 项目 | 内容 |
|---|---|
| **提出人** | 周明灏 |
| **问题** | 原文"依据正确率给出评价等级（优秀 / 良好 / 加油）"——未定义分界值 |
| **处理** | ✅ **采纳**。补充：正确率 ≥ 95% 为"优秀"，80% ~ 95% 为"良好"，< 80% 为"加油" |
| **状态** | 已修复 |

### P-08【歧义】"题量"指卷子题量还是每次练习题量？

| 项目 | 内容 |
|---|---|
| **提出人** | 周明灏 |
| **问题** | FR-08 中"题量"与 FR-17 中"题量"的指代可能不一致 |
| **处理** | ✅ **采纳**。在术语表中明确区分：**题量**（组卷时指定的题目数量）与**作答题数**（一次练习中实际作答的数量，可能因跳过而少于题量） |
| **状态** | 已修复 |

### P-09【歧义】"知识点掌握度"的计算口径

| 项目 | 内容 |
|---|---|
| **提出人** | 屠生豪 |
| **问题** | FR-23 中"掌握度"未说明是否包含错题重练的记录 |
| **处理** | ✅ **采纳**。明确：掌握度 = 该知识点下**全部作答记录**（含首次练习与错题重练）中答对的题数 ÷ 总作答题数；错题重练的记录**计入**，因为重练答对说明已掌握 |
| **状态** | 已修复 |

### P-10【歧义】"同一道题"的判定标准

| 项目 | 内容 |
|---|---|
| **提出人** | 周明灏 |
| **问题** | FR-18 第 5 条"同一道题再次答错"——`37+25` 和 `25+37` 算不算同一道？ |
| **处理** | ✅ **采纳**。明确判定规则：按 `知识点 + 规范化后的表达式` 判重；加法与乘法**交换律视为同一题**（`37+25` ≡ `25+37`），减法与除法不适用 |
| **状态** | 已修复 |

### P-11【优先级】FR-20 举一反三应从 Should 提升为 Must

| 项目 | 内容 |
|---|---|
| **提出人** | 家长 B（用户代表） |
| **原文** | "**举一反三**！这个是我最想要的。她错了一道 408÷4，我希望软件能立刻给我出 5 道同类型的。" |
| **讨论** | 屠生豪担心实现复杂度。经讨论，举一反三与组卷引擎共用同一套生成器，仅需额外实现"参数提取 + 同型重生成"，工作量约 0.5 人日，可控 |
| **处理** | ✅ **采纳**。FR-20 优先级由 Should 提升为 **Must** |
| **状态** | 已修复 |

### P-12【非功能】NFR-03 可靠性未量化

| 项目 | 内容 |
|---|---|
| **提出人** | 周明灏 |
| **问题** | 原文"优雅降级，不导致白屏"——"优雅"不可测 |
| **处理** | ✅ **采纳**。改为：当 localStorage 数据解析失败时，系统应捕获异常、清空损坏数据、以全新状态启动，并向用户展示"本地数据损坏，已重置"的提示；全程不出现白屏 |
| **状态** | 已修复 |

### P-13【非功能】NFR-06 可访问性缺少对比度例外说明

| 项目 | 内容 |
|---|---|
| **提出人** | 屠生豪 |
| **问题** | 正文对比度 ≥ 4.5:1 是合理的，但图表中的状态色（如"待加强"的黄色）在浅色背景上难以达到 4.5:1 |
| **处理** | ✅ **采纳**。补充说明：正文与关键交互元素须满足 4.5:1；**图表中的非文本图形元素**（色块、折线）须满足 3:1；且必须同时以图标 + 文字标签辅助表达，不得仅依赖颜色 |
| **状态** | 已修复 |
