## 6. 每个人交什么、如何验收

每包提交自己的功能分支、实际改动文件列表、需求→实现→测试对应表、可重复的测试数据与命令、真实执行结果、手机/电脑检查记录、操作说明和未完成清单。新增验证状态先为“未执行”，测试后填写结果。不要提交他人浏览器数据、令牌或自行编造的试用反馈。

黄磊负责按依赖顺序合并、接入共享入口、运行现有与新增回归、检查白色界面及移动端、确认数据跨模块一致、汇总测试报告与使用说明，再按用户发布指令同步 Gitee/GitHub 与在线演示。这些是统一集成职责，不占 A/B/C 的功能份额。

本期不开发：任何练习卷/答案页/错题打印或 PDF、OCR、云账号/跨端自动同步、排行榜、老师班级后台。FR-28 JSON 备份继续开发。
