日期：2026-10-26。任务负责人：黄磊；本轮实现、文档与自动化由 AI 辅助完成。仅本地修改，未提交、推送或更新在线网页。需求 SRS V1.4 不变；设计更新至 SDD V1.7 §5.4.2、§12、§13.7。

## 1. 复现的问题与修复

修改前使用独立浏览器记录 `.tmp/b07-baseline.json`：首页进入、进入出题页、生成预览、首次答错、退出按 Escape 后均出现 activeElement=BODY；原生知识点复选框按 Enter 未切换；答案输入后的第一次 Tab 到提交按钮，但视觉中键盘位于提交之前。

| 问题 | 本地修复 | 依据 |
|---|---|---|
| 切页焦点无起点 | 路由调用 focusPage，保留页面主动聚焦，否则定位标题/首控件 | AC-KB.5 |
| 预览、反馈、模态取消及历史加载后丢失焦点 | 各局部重绘显式定位预览标题、输入、下一题、退出按钮、首条新增记录 | AC-KB.1/5 |
| Tab 顺序与视觉不符 | 调整答题控件 DOM，键盘先于提交/跳过；键盘激活数字键保留按钮焦点 | AC-KB.1/2/4 |
| 复选框 Enter 与长按激活 | 原生 Space 保留；增加 Enter 切换，捕获 repeat 激活，普通数字长按不拦截 | AC-KB.2/4 |
| 非法答案缺少输入关联 | aria-invalid、answer-error 关联、定位输入，编辑后清除标记 | FR-12/13；NFR-06 |
| 取消离开恢复旧 start 参数与导航高亮 | route.render 后同步同路由实际 URL；导航在离开确认处理后读取地址 | B07 返回/切页；FR-14 进度保留 |

错误反馈、计时、首次计分、订正次数与存储格式没有改动。没有完成或假装完成 A/C 业务模块。

## 2. 改动与边界

| 文件 | 作用 |
|---|---|
| `src/utils/accessibility.js` | focusElement/focusPage/installKeyboardSupport，不读写业务数据 |
| `src/main.js`、`src/core/router.js` | 启动键盘辅助、切页焦点、实际路由及导航高亮 |
| `src/ui/pages/practice.js` | 出题后焦点落在可聚焦预览标题，立即滚动展示；失败保留出题入口 |
| `src/ui/pages/quiz.js` | 稳定控件 ID、输入/反馈焦点、错误关联、dialog 取消恢复与 Tab 闭环 |
| `src/ui/components/keypad.js` | 键盘激活保留按键焦点，鼠标点击保留既有 focusInput 行为 |
| `src/ui/pages/history.js` | 加载更多后聚焦首条新增记录，避免按钮消失后掉到 BODY |
| `tests/keyboard-browser.cjs` | 独立数据、键盘操作、焦点与模态边界自动化 |

焦点轮廓沿用现有 CSS 的 2px 实线；标题/静态容器只使用 tabindex=-1，不使用正 tabindex，也不把普通页面全局困在焦点循环中。dialog 内单独限制 Tab 是模态交互规则；页面末尾进入浏览器工具栏不作为本应用控件，测试不越过页面边界强行循环。

## 4. 手动复现与未覆盖项

```bash
node tests/keyboard-browser.cjs
node tests/mobile-quiz-browser.cjs
node tests/quiz-browser.cjs
python scripts/serve.py --port 8765
```

脚本默认 Windows Edge，可设置 EDGE_PATH；本机沿用已有 NODE_PATH。预览：`http://127.0.0.1:8765/?preview=b07#/practice`。

复现：Tab/Shift+Tab移动，Enter/Space操作按钮或知识点，输入答案后Enter提交；答错可Tab至再试一次；Shift+Tab从答案回到退出，Escape取消。首次成绩保持原规则。

实现参考 [W3C 复选框模式](https://www.w3.org/WAI/ARIA/apg/patterns/checkbox/) 与 [W3C 模态对话框模式](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)。Enter切换复选框是课程 AC-KB.2 的额外要求；W3C复选框模式规定的核心激活键是Space。模态Tab限制与关闭后焦点返回按对话框模式处理。

通过范围为当前已注册页面与已实现路径。错题本仅验证现有占位页；A/C尚未实现的新增页面、真实手机/iOS Safari、真实输入法与读屏软件没有宣称通过，集成后应追加验收。没有把本次键盘检查当作全部非功能指标通过。
