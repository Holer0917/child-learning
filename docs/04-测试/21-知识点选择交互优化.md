# 知识点选择交互优化

日期：2026-10-31（Asia/Shanghai）。用户要求：手机出题页知识点列表过长，改成一个入口，选完退出。

## 1. 交互变化

- 出题页仅显示“已选N个知识点”、至多两个名称的摘要和选择入口。
- 手机宽度≤700px时打开全屏选择面板，电脑打开居中面板。头部提供取消与年级；底部保留已选数量与“确认选择”；列表在中间独立滚动。
- 保留24个知识点、年级默认组合、关键词检索、顺序/难度/说明/支持题型及全选/全不选/反选。
- 选择过程修改草稿；确认后才应用。取消或非输入法组合中的Escape丢弃草稿。重开时保留已确认知识点、清空搜索词。
- 已确认范围实际改变才清除旧试卷；无变化确认或取消保留原试卷。题量、难度、题型、倒计时不因面板操作重置。
- 初始聚焦标题，Tab/Shift+Tab在面板控件内循环；返回后恢复入口焦点与原滚动位置；切换路由后释放滚动锁。

## 2. 基线与实现

需求仍为SRS V1.5，25条有效FR/141条功能AC；本次落实FR-04/05/06和AC-KB既有能力，不增加需求或存储字段。设计更新为SDD V1.12 §13.12。主体改动为practice.js和base.css；无新增模块、依赖或构建步骤。

正式SW升至abc-3，测试副本为abc-preview-3，缓存资源仍为36个JS模块/42个资源。保持既有正式/测试存储命名空间及温和更新方式，不强制接管正在练习的旧页面。

为满足原300000字节运行资源目标，样式去除冗余空格与末尾分号，保留规则换行和注释；删除经源码检索确认无引用的旧掌握度分组、旧统计头部和占位页等样式。当前掌握度等级色、纹理及实际页面选择器保留。
