# B09 答题反馈：本地实现与验证记录

日期：2026-10-27。任务负责人：黄磊；实现、自动化和文档由 AI 辅助完成。仅在本地修改，未提交、推送或更新在线网页。需求基线仍为 SRS V1.4；设计更新至 SDD V1.9 §13.9。

## 1. 本步交付

| 需求 | 实现与判定口径 |
|---|---|
| AC-15.1 | 正确提交后文字轻微淡入/位移，CSS 动画 300ms；无遮罩、不等待动画完成，下一题按钮立即可操作，原有 700ms 自动切题不延长 |
| AC-15.2 | 按本次题序、截至当前题的首次作答倒序计算连续正确次数；5 题起显示“连对 N 题”；错误、跳过、未答中断，订正不补入 |
| AC-15.3 | total>0 且 correct=total、wrong=0、skipped=0 时显示“全对”；本次成绩播放 300ms 轻量庆祝，历史详情只显示文字 |
| AC-15.4 | 答题页提供原生按钮开关，aria-pressed 标明状态；首次默认关闭，沿用 km:settings.sound 布尔字段，保留 settings 其它字段 |
| AC-15.5 | 主动开启后，提交正确/错误分别调度上行双音/低单音；跳过、无效输入、刷新恢复与自动切题不播音；音效异常只影响音效 |
| NFR-02/06 | 保留白底、44px 控件与已有焦点；系统请求减少动态效果时保留静态文字，免除非必要动画；此为明确的可访问性适配条件 |

FR-15 保持 Could，不新增积分、排行、奖品或彩色装饰。A/C 模块不属于本步交付。

## 2. 实际执行结果

运行 `node tests/feedback-browser.cjs`，隔离 Edge 156.0.4314.42、随机本机端口与独立存储。测试使用真实出题和会话接口准备数据；页面上的输入、判分、订正、切题与结算走现有路径。11 组通过，未捕获页面 JavaScript 异常。浏览器缺 API、拒绝 resume、延迟 resume 和容量不足属于隔离环境故障注入。

| 组 | 输入与操作 | 判定与结果 |
|---|---|---|
| 1 | 首次打开；输入 abc、正确答案；动效仍在播放时立即点击下一题；再跳过 | abc 不写 Attempt；正确反馈 0.3s/300ms；下一题立即进入第2题，900ms 后未双跳；默认不创建 AudioContext，通过 |
| 2 | 连续正确5题，退出取消、刷新继续，再正确1题 | 前4题无连对提示；第5/6题显示对应次数；重绘/恢复无动画与声音重播，通过 |
| 3 | 首题错误后订正，之后连续对4题；跳过后再答对；退出结算 | 订正不覆盖首次错误，不凑成连对5题；跳过中断，成绩无“全对”庆祝，通过 |
| 4 | 5题全部首次正确；结算后打开相同历史详情 | 本次结果显示“全对”及300ms动画；历史仅文字，没有额外音效，通过 |
| 5 | 开启→正确→错误→关闭→订正；刷新；再次开启后刷新 | 真实 Web Audio 调度660/880/220Hz，1个上下文且运行状态为running；开关保留焦点；关闭后无新增音符，刷新保留选择但不自动创建音频；原settings其它字段保留，通过 |
| 6 | AudioContext 缺失或 resume 拒绝 | 显示音效不可用；正确/错误文字和下一题仍可用，无未处理拒绝，通过 |
| 7 | resume 未完成时关闭声音或退出，再解除延迟 | 无迟到音符；可直接结算并释放上下文，通过 |
| 8 | 仅设置键写入抛 QuotaExceededError；保存字符串 sound="true" | 写失败提示仅本次有效，作答仍能保存；非法偏好回落静音，通过 |
| 9 | reduced-motion=reduce | 动画名none、文字完整、下一题可立即操作，通过 |
| 10 | 360×640、390×844、667×375横屏、1440×900 | 无横向溢出，开关100×44px、白色背景，通过 |
| 11 | 正确提交后不操作，等待自动下一题 | 沿用700ms，仅产生1次首次提交并前进1题，通过 |

## 3. 预览与限制

内置浏览器在8765上检查新版本答题页；留有一份5题、零作答的体验会话，没有新增成绩或清除旧记录。新设置代码修改后重新加载已确认。预览曾因残留的同端口旧服务无响应，核对命令后停止残留实例，恢复HTTP 200，保持原地址。

自动化确认的是浏览器节点、参数、运行状态与流程，**没有通过扬声器人工听音**。真实手机的音量、静音模式、系统减少动态效果设置及 iOS/Safari 音频策略尚待实机验收；本轮没有安装到操作系统。B10 的最终汇总及 A/C 集成验收仍待后续。

## 4. 查阅依据

音频只在开启/提交的交互内创建或恢复，保持可关闭，参考 [MDN Web Audio 最佳实践](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices)。减少动态效果的适配参考 [MDN prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)。上述资料用于设计选择，不作为本机或真实手机已测通过的证据。
