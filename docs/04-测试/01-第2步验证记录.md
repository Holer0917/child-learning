# 第 2 步：答题、判分与成绩验证

日期：2026-10-22。执行主体：AI 使用本地 Node 24 与 Edge / Playwright 自动化；不记作人工实机验收。

## 交付范围

- FR-12：逐题答题、进度、触屏键盘、实体键盘输入/回车、跳过、退出确认。
- FR-13：即时判分，答对后自动下一题；答错显示答案且允许订正一次，首次成绩保留。
- FR-14：计时与可选的 1～60 分钟倒计时，超时结算；时间戳计算包含后台与刷新时间。
- FR-16：正确/错误/未作答、正确率、等级、总耗时与有效作答平均耗时、知识点构成、错题明细、档案内保存。
- 为刷新恢复增加会话字段校验、草稿保存和 24 小时有效期；结算写入 `sessions:<pid>`，按 500 条完整明细与 2000 条摘要保留。历史列表、错题本、打印仍为后续任务。

## 执行方法

```powershell
node --test tests/quiz-session.test.mjs
node tests/quiz-browser.cjs
```

需 Node 22 或更新版本；浏览器用例另需 Playwright 包（可用 `NODE_PATH` 指向外部测试依赖目录）与 Edge。业务运行代码不依赖这些测试工具。

浏览器脚本自建临时 HTTP 服务，使用独立浏览器数据目录，用例结束自动关闭服务与浏览器。

## 数据兼容与实现说明

需求基线继续沿用实验 1 SRS V1.3。临时会话在设计说明书 §6.2.I 的字段上增加 `schemaVersion`、`id`、`questionAt`、`draft`、`retries`，分别用于恢复格式校验、幂等结算、单题计时、草稿与订正保存；首次作答保存在 `attempts`，订正在 `retries` 中以 `first:false` 保存。

为结果页刷新读取增加 `km:quiz:result:<pid>`，只保留最近一次结果。完整历史仍以 `km:sessions:<pid>` 为准。存储失败时保留内存中的本次结果与磁盘中原有恢复点，并显示警告。

本阶段未对真机 iOS Safari、真机 Android、读屏软件、离线安装、打印和全部 161 条验收用例进行验收。手机布局结论来自 Edge 的视口模拟；性能指标与可用性指标仍需后续专项测试。
