# 手机答题单屏布局

2026-10-31：按用户要求，答题页隐藏离线检查、安装提示及页脚，手机端同时隐藏全站顶栏；离线能力保留，其入口在其它页面仍可使用。

手机端压缩题头、进度、题干、输入与反馈间距；普通竖屏四列键盘，矮屏并排题目和键盘，短横屏四列键盘。保留32px题目、44px触控区、计时、提示音、退出与订正。短横屏收起输入格式提示，保留实际题干和输入控件。

在原手机回归的5类边界题×9种尺寸中增加整页scrollHeight≤innerHeight+1断言，不以禁止滚动或裁切遮掩溢出。45组覆盖320×568、360×480、568×320等视口。模拟检查不代表所有真实设备和系统字体设置均已人工验收。

沿用SRS V1.5/SDD V1.13，范围为既有FR-12与移动兼容需求的实现优化，不改变判分、会话、存储或需求编号。正式/测试SW为abc-5/abc-preview-5。原始结果见[evidence](evidence/Quiz-fit-20261031/summary.json)，发布完成后另补结果。

补充：手机判题反馈时收起已禁用的键盘，订正时恢复；另用独立浏览器核对四种尺寸答错反馈页的scrollHeight等于视口高度，保证操作区不被挤出。短横屏输入标签视觉收起但仍保留关联名称，竖式保持32px字号。

最终回归：77项逻辑、138组浏览器检查通过，45组边界尺寸满足整页无纵向滚动；4组答错反馈视口通过。独立测试副本80项逻辑/隔离、43组浏览器检查通过。
