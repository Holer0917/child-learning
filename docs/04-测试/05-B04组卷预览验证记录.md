## 2. 数据与文件

`src/domain/paper.js` 新增 `calculatePaperStats(questions)`，返回 `{total,avgStar,dist}`，不改输入。total 为当前题数；avgStar 为星级总和/题数并四舍五入到一位小数；dist 按 kpId 累计。空数组返回 total=0、avgStar=0、dist={}。

`generator.js` 返回值增加 Paper.stats；旧函数签名、知识点约束和去重键不变。`practice.js` 用同一函数从当前题目计算预览，知识点名称来自 syllabus；占比独立四舍五入，合计可为 99% 或 101%，页面作了说明。旧 Paper 无 stats 仍由既有会话验证接受，未迁移或清除旧数据。

改动：上述三个源文件、`assets/css/base.css`；新增 `tests/paper-stats.test.mjs`、`tests/preview-browser.cjs`；更新 README、交接、分工和 SDD。B05 调整题目后应复用统计函数同步 Paper.stats 与实际 count。
