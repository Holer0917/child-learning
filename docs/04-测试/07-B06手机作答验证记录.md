## 2. 行为与改动文件

- `src/ui/components/keypad.js`：新增可选第三参数 `{mode,focusInput}`。整数/小数/分数/余数各 12 键，比较 4 键；比较改选替换整项。触屏点键不主动聚焦，避免由页面主动唤起系统键盘；保留光标选区、退格、40 字上限与禁用态。
- `src/ui/pages/quiz.js`：按题目选择键盘并显示输入格式提示；竖式完整文字题干关联输入框，视觉去除重复横式；进入/提交/下一题/重试时滚回题目，校验失败保留输入并定位输入框。
- `assets/css/base.css`：触屏答题导航简化、安全区内边距、短屏紧凑布局及横屏并排；白色极简风格保持。
- `tests/mobile-quiz-browser.cjs`：新增独立浏览器验证；不使用用户浏览器数据。README、交接、分工及 SDD 同步本地进度。

没有改动生成器、判分器、quizSession、存储键或首次计分规则。本轮发现并修复：按键自动滚动到页面下方后，进入下一题会沿用旧滚动位置而看不到题干；触屏切题现在重新定位题干。

### 截图与测试工具修正

诊断发现，本机 Playwright/Edge 的 `fullPage:true` 截图后会将 `(pointer:coarse)` 从 true 改为 false，造成后续触屏布局检查失真。独立探针复现后，正式测试将截图放在独立上下文，使用视口截图，并在布局检查及截图前后显式断言 coarse=true；没有放宽布局判据。截图 `.tmp/b06-quiz-390x844.png`、`.tmp/b06-quiz-667x375.png` 为本机产物，不自动发布。

另在用户使用的内置浏览器通过界面选择三年级同分母分数加减法、5 题并开始，确认分数题干、格式提示、12 键及提交/跳过显示正常。标签页与 `.tmp/b06-preview-live.png` 已保留；停在第 1 题供查看，未提交答案、未产生新成绩。此项仍是桌面内置浏览器检查。

## 4. 复现与限制

```bash
node tests/mobile-quiz-browser.cjs
node tests/quiz-browser.cjs
python scripts/serve.py --port 8765
```

脚本默认使用 Windows Edge，可设置 EDGE_PATH；本机沿用已有 NODE_PATH。预览：`http://127.0.0.1:8765/?preview=b06#/practice`，出题后点击开始答题查看各类键盘。

已查阅 [HTML 输入模式规范](https://html.spec.whatwg.org/multipage/interaction.html#input-modalities:-the-inputmode-attribute) 与 [CSS env 安全区说明](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/env)：inputmode=none 是给浏览器的输入方式提示，安全区值由设备/浏览器提供。模拟测试不证明真实 Android/iOS 的系统键盘、刘海安全区、浏览器工具栏或所有缩放状态已经通过；这些留待实机验收。桌面完整键盘路径与真实读屏仍待 B07。
