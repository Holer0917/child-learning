## 2. 文件与缓存约定

- `sw.js`：VERSION=b08-2；ASSETS覆盖26个运行模块、入口HTML、CSS、manifest及3个PNG，共32资源。缓存键按作用域路径与版本隔离。完整安装、查询就绪、失败候选清理、waiting更新及联网修复；无skipWaiting/自动刷新，无localStorage访问。
- `src/app/pwa.js`：register/update、MessageChannel状态/修复、失败重试、安装事件及指引；只查询本应用作用域。查询3秒/修复30秒超时，按钮内防并发。
- `manifest.webmanifest`、`assets/icons/*.png`：相对id/scope/start_url、standalone、白色主题。图标由 `scripts/generate-icons.py` 的几何图形生成，没有使用未采用的彩色美术；脚本仅开发再生成使用，不是部署步骤。
- `index.html`、`src/main.js`、CSS及键盘辅助：入口引用、页脚状态/操作、白色布局与键盘作用域接入。
- `scripts/serve.py`：默认8765为编辑预览，注入开发标记并跳过SW；`--pwa --port 8766`提供原始静态文件用于离线验证。不同端口的数据独立，不迁移、不清除。

新增运行资源必须加入ASSETS；发布任何缓存资源修改必须递增VERSION。新资源完整后等待全部旧应用页面关闭，再激活，仅清理同作用域旧版本。漏递增时拒绝覆盖同名缓存。缓存修复仅在没有新版安装/等待时请求，避免将新版资源写入旧版本缓存。

## 4. 复现与限制

```bash
node tests/pwa-browser.cjs
node tests/keyboard-browser.cjs
node tests/mobile-quiz-browser.cjs
python scripts/serve.py --port 8765
# 另开终端：
python scripts/serve.py --pwa --port 8766
```

本机沿用已有NODE_PATH，脚本默认Windows Edge，可设置EDGE_PATH。缓存与截图为忽略的本机测试产物，不自动上传。使用步骤见 [离线与安装](../05-使用说明/01-离线与安装.md)。

核对依据：[MDN SW生命周期](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers)、[更新缓存策略](https://developer.mozilla.org/en-US/docs/Web/API/ServiceWorkerRegistration/updateViaCache)、[安装事件适用范围](https://developer.mozilla.org/en-US/docs/Web/API/BeforeInstallPromptEvent)、[manifest相对start_url](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Manifest/Reference/start_url)。安装事件不是所有浏览器都提供，故保留菜单指引，不据此宣称所有设备支持原生提示。

真实iOS/Android主屏幕安装、系统存储回收、Safari/Firefox兼容以及A/C新增页面/资源待补验。开发服务器只绑定127.0.0.1，手机不能直接打开电脑的这个地址；本轮不增加网络暴露或发布网页。本轮停在B08，下一步B09为可选轻量反馈，B10最终汇总待完成。
