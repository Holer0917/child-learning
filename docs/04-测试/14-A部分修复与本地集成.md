## 2. 补齐的功能

- 错题按知识点分组、显示各组数量；保留状态和知识点筛选、勾选、分页、空状态。
- 答错后的“举一反三”先询问结束并保存当前练习，随后创建独立变式会话；成绩页也提供单题变式入口。
- 变式成绩页提供“再来一组”和“继续下一批”，下一组排除上一组题目；最初原卷的排除键独立保存在错题中，原卷压缩/移出保留窗口后仍可排除。
- 趋势少于2次显示不足，支持7/30次或全部、环比上升/下降/持平和文字数据表。
- 掌握度按升序显示条形图与文字/符号等级，列薄弱前三名；快捷入口选中对应知识点，无有效作答时显示未练习。
- 滚动8周共56天日历、有效练习量、7/30/100天徽章及获得日期；已获得徽章不因打卡中断或记录移出窗口而撤回。
- 手机及电脑继续白底；新增页面保留≥44px按钮，错题题干≥32px。统计页跨自然日重算，并在离开时清理定时器。

## 3. 运行与数据约定

需求仍为 SRS V1.4；设计更新为 SDD V1.10 §13.10。生成器的已冻结导出签名和卷内去重行为不改。错题专用JSON键包含题型、空位及比较目标，修正此前共用数学表达式键的设计偏差；V1完整快照在内存中重新计算键，业务成功写入才升级。

| 分区/字段 | 内容 | C 部分接入时必须保留 |
|---|---|---|
| `km:mistakes:<pid>` | `{version:2,archivedSessions:string[],items:Mistake[]}` | 整体备份防重ID；清理错题不清除ID |
| `Mistake`新增字段 | `firstUserAnswer`、完整`question`、`sourceSessions`、`sourcePaperKeys`、`masteredAt` | 未知版本/错误结构拒绝覆盖；旧记录不伪造已丢失字段 |
| `km:badges:<pid>` | `{version:1,items:[{id,earnedAt}]}`，ID为d7/d30/d100，日期YYYY-MM-DD | 保存历史获得日期，不只按当前连续天数重算 |
| 练习Paper | `retry`/`variant`、`sourceMistakeIds`、`variantRemainingIds`、`variantPreviousKeys` | 未完成练习恢复应保留模式、来源及剩余批次 |
| `sessions:<pid>` / `quiz:result:<pid>` | 成绩为归档恢复来源，最近结果可带保存状态提示 | 归档重试不新增第二条成绩 |

归档顺序为先保存成绩，再写单个错题容器（条目和防重标记同键）；跨键不宣称数据库事务。归档失败时不回滚已保存成绩，由成绩页/错题本显式重试。仅回补已保留的完整成绩，不从摘要猜测原题。防重窗口与2500条历史窗口对齐，不对已移出窗口又被外部重新注入的历史ID承诺无限期防重。

C 的备份/导入与档案级联删除代码尚未提供，本次只形成接入契约，不宣称 C 已完成。多标签页并发写入、所有容量组合的实机空间占用仍未验收。
