# 电脑端宽屏适配正式发布

2026-11-01。用户授权将测试版电脑端适配同步至正式仓库。来源测试提交`b840a96cfb06e2a433cbdc812d56c15765d1c077`。

1100px及以上视口使用自适应宽度，外框铺满可用窗口，保留24～64px两侧留白。统计页采用两栏，练习足迹通栏；数据管理采用三栏，页面标题通栏。短页面外框至少占满视口高度。答题和结算内容仍保留适合阅读的宽度，手机布局规则不变。

正式版仅同步CSS、对应布局测试与说明，正式SW由abc-14递增到abc-15。index、manifest、存储前缀及所有业务JS均不变，测试站继续使用abc-preview-23。

正式本地版通过56组路由/尺寸检查，覆盖390、1024、1099、1100、1280、1440、1920、2560px，检查无横向溢出、桌面外框宽度、统计/数据管理分栏和短页页脚位置。证据见[evidence/Desktop-wide-20261101](evidence/Desktop-wide-20261101/)。可用`node tests/desktop-layout.cjs`复跑，设置LAYOUT_SITE可验证公开站。截图与检查来自隔离Edge及模拟视口，不声称实际F11或真实显示器验收。

本次同时将正式网页入口移至README标题下方，便于直接访问。正式GitHub main和Gitee master同步同一提交，发布后核对Pages与公开CSS/SW。
