# 答题反馈与提示音

本说明适用于2026-10-27的本地B09版本，尚未同步到线上。

1. 从“出题练习”生成题目并开始答题。答对后有300毫秒的轻微文字动效，可以立即点击下一题，也可以等待原有自动切题。
2. 连续首次答对5题起，会显示“连对 N 题”。答错、跳过会中断连续次数；订正正确不会改写首次成绩或补进连对。
3. 本次所有题都首次答对，成绩页显示“全对”庆祝。查看历史时保留文字，不重复播放庆祝。
4. 提示音默认关闭。需要声音时，点击答题页右上方“提示音：关闭”，再次点击可关闭；选择保存在当前浏览器与网站地址中。开启后答对/答错有不同短音，跳过不响。
5. 音效不可用时仍可正常作答；按提示关闭后重新开启重试。浏览器、系统静音或设备音量也可能影响声音。刷新或恢复练习不会自动播放旧题音效。

系统启用“减少动态效果”时只保留文字反馈。音效开关可以通过Tab到达，以Enter或空格操作，状态随按钮文字和按下状态变化。

本地即时预览：[打开练习](http://127.0.0.1:8765/?preview=b09#/home)。离线准备及安装说明见 [离线与安装](01-离线与安装.md)。不同端口/浏览器的数据独立，真实手机与扬声器听音尚待验收。
