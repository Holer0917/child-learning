# 档案与备份恢复

适用：本地ABC版，2026-10-30。当前在线独立测试站仍为此前A+B，尚未发布这些C功能。

## 1. 学习档案

点击顶栏“档案”或头像区域。每个浏览器最多3个档案，首次自动建立的“小朋友”也占一个名额，可以直接编辑。

- 创建时选择1/2/3年级与头像，昵称最长12个字符；留空使用“小朋友”。
- 切换到另一个孩子后，只显示该档案的历史、错题和统计。有进行中练习时先确认，原进度保留，切回可继续。
- 删除需要确认，清理该孩子的历史、错题、徽章与进行中练习。删除最后一个档案后引导创建，不会刷新后悄悄新增默认档案。

## 2. 历史筛选与删除

在“成绩历史”选择最近5/10/30次或全部，输入起止日期、选择知识点。日期包含当天；开始晚于结束会提示。可以清空日期或改为全部知识点，无结果时也可点击“清除筛选”。

单条删除需要确认。删除后历史统计按剩余记录更新，独立错题仍保留，已删除记录的详情链接显示找不到记录。

## 3. 导出与恢复

进入顶栏“数据管理”，点击“导出备份”，确认浏览器已保存`kidsmath-backup-YYYYMMDD.json`。文件包含档案、成绩、错题、防重记录、徽章、未完成练习和音效设置。

恢复时选择不超过5MB的JSON文件。完整校验通过才显示预览；结构错误会报告字段路径，不会覆盖当前数据。

- **合并**：默认方式。按编号去重，成绩保留结束时间较新的记录，临时练习保留保存时间较新的那份；同题错题不重复累加，徽章保留较早获得日期。合并后仍不能超过3档案。
- **覆盖**：替换现有档案数据，备份之外的档案会被移除。先导出当前备份，再检查预览并确认。

点击“确认导入”后还有一次确认；取消不改变数据。成功后显示恢复后的档案、成绩和错题数量。备份含音效设置时一同恢复，早期文件没有设置则保留现有偏好。合法但超过24小时的未完成练习会提示后忽略，其余数据仍可恢复。

## 4. 失败时处理

暂存空间不足时导入不生效，原值不改。中途写入失败会按持久日志恢复；如果恢复尚未完成，界面明确提示并提供“重试数据恢复”。恢复浏览器存储权限或释放可用空间后重试，保留备份文件和恢复日志。

重开时若出现恢复界面，先完成恢复再进入应用。不要为了处理导入错误而直接清空本应用浏览器数据，因为那会删除恢复依据。存储不可用时只允许临时练习，开关会提示仅本次打开有效，导入不会伪装成已持久保存。

数据按浏览器和地址保存，本地127.0.0.1、正式网站与独立测试站的数据不是同一份。本轮没有自动同步到云端，也没有推送仓库或在线网页。
