# 离线使用与添加到主屏幕

本说明适用于本地B08版本，尚未同步到线上。

## 1. 第一次准备

1. 联网打开页面，在页脚等待“离线已就绪”。
2. 再断网，可继续出题、作答、查看本机成绩；刷新后也可打开。
3. 从未访问或未完成缓存时，需要先联网打开。浏览器缓存被回收后，联网点击“检查更新 / 重试离线”，等待重新就绪。

离线失败不会自动删除学习记录。记录属于当前浏览器与网站地址，不会自动同步到另一台设备或浏览器。

## 2. 添加图标

点击页脚“添加到主屏幕”：浏览器提供安装提示时按提示完成；没有提示时按显示的浏览器菜单指引操作。取消安装仍可使用网页。

iPhone：在Safari打开，使用共享菜单中的“添加到主屏幕”，按系统提示添加；部分版本可选择作为网页App打开。操作位置可能随版本或布局变化，参见 [Apple官方说明](https://support.apple.com/zh-cn/guide/iphone/iphea86e5236/27/ios/27)。其它浏览器在菜单中查找“安装应用”或“添加到主屏幕”。

安装到主屏幕不等于完成离线缓存；仍需看到“离线已就绪”。本项目已提供清单、图标与入口，真实手机安装尚待验收。

## 3. 更新与重试

- 联网点击“检查更新 / 重试离线”。
- 显示新版已准备好时，可先完成当前练习，再关闭所有本应用页面及独立应用窗口，重新打开使用新版。
- 准备或更新失败时仍可使用已有版本，联网后重试；不要为更新而清除浏览器学习数据。
- 若看到“暂时无法离线打开”，先恢复网络，再点“重新打开”并等待准备完成。

## 4. 本地预览地址

| 用途 | 启动命令 | 地址 |
|---|---|---|
| 日常编辑，刷新查看代码修改 | `python scripts/serve.py --port 8765` | http://127.0.0.1:8765/#/practice |
| 离线与PWA验证 | `python scripts/serve.py --pwa --port 8766` | http://127.0.0.1:8766/#/home |

两个端口的学习数据分别存储，8766显示空历史不表示8765的数据丢失。这两个地址只供当前电脑使用；本轮没有上线或开放局域网访问。线上版本是否更新以发布记录为准。
